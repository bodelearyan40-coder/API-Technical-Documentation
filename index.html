API Technical Documentation

A beginner-friendly reference for understanding and using a sample Student Management API.

About this project

This website demonstrates how API documentation is organised. The endpoints and responses are illustrative examples; no live API server is connected.

What is an API?

An Application Programming Interface (API) defines how software applications can communicate with each other. API documentation describes the available endpoints, required parameters, request formats and expected responses.

About this API

The Student Management API is a sample API designed to demonstrate common operations on student records, such as retrieving, creating, updating and deleting records.

HTTP Methods

HTTP methods describe the type of operation requested from an API.

MethodPurposeExample
GETRetrieve dataList students
POSTCreate a recordAdd a student

GET

List Students

Returns a collection of student records.

/students

Parameters

No required parameters in this example.

Example response

{
  "success": true,
  "count": 2,
  "data": [
    {
      "id": 1,
      "name": "Aarav Sharma",
      "course": "Information Technology",
      "semester": 3
    },
    {
      "id": 2,
      "name": "Priya Verma",
      "course": "Information Technology",
      "semester": 3
    }
  ]
}
GET

Get a Student

Returns one student record by its unique ID.

/students/{id}

Path parameter

ParameterTypeDescription
idIntegerUnique student identifier

Example response

{
  "success": true,
  "data": {
    "id": 1,
    "name": "Aarav Sharma",
    "course": "Information Technology",
    "semester": 3
  }
}
POST

Create a Student

Illustrates creating a new student record.

/students

Example request body

{
  "name": "Rahul Patil",
  "course": "Information Technology",
  "semester": 3
}

Example response

{
  "success": true,
  "message": "Student created successfully",
  "data": {
    "id": 3,
    "name": "Rahul Patil",
    "course": "Information Technology",
    "semester": 3
  }
}
PUT

Update a Student

Illustrates updating an existing student record by ID.

/students/{id}

Example request body

{
  "name": "Rahul Patil",
  "course": "Information Technology",
  "semester": 4
}

Example response

{
  "success": true,
  "message": "Student updated successfully"
}
DELETE

Delete a Student

Illustrates deleting a student record by ID.

/students/{id}

Example response

  "success": true,
